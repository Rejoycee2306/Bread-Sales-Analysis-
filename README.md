Fortunate Bread Sales Analysis 

‎Overview

‎This project analyzes Fortunate Bread Sales data to understand sales trend and product performance. 

‎Tools Used:

‎Microsoft Excel 
‎Data Analysis Toolpak 

‎Process:

‎Data cleaning and preparation 
‎Descriptive statistical analysis
‎Pivot tables
‎Charts and dashboard 

‎Key insights:

‎- Extra-large bread sizes recorded the highest sales, indicating preference for premium -priced products 
‎-Sales performance varied significantly across states, with some states outperforming others. 
‎-Sales peaked during mid-year and festive months( July-September and December).
